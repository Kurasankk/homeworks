# Анализ гемоглобина

Проект выполняет анализ данных пациентов из Excel-файла и сохраняет результат в CSV-файл с усреднёнными значениями гемоглобина по возрастным группам.

## Структура проекта

hem/
├── data/
│ └── Пациенты.xlsx # исходные данные
├── script.R # R-скрипт анализа
├── Dockerfile # инструкция для сборки Docker-образа
└── Readme.md # этот файл

## Требования

- Docker (любая актуальная версия)
- Доступ к интернету при первой сборке (для установки пакета `readxl`)

## Сборка Docker-образа

Находясь в папке проекта `hem/` выполните:

docker build -t r-analysis .
-t r-analysis — имя создаваемого образа.

Dockerfile берёт за основу официальный образ rocker/r-base и устанавливает пакет readxl.

Для запуска контейнера и анализа данных используйте:

docker run -v "$(pwd)/data:/data" r-analysis

Скрипт внутри контейнера читает файл /data/Пациенты.xlsx и сохраняет результат в /data/анализ_гемоглобина.csv.

## Результат
После успешного выполнения команды в папке data/ появится файл:анализ_гемоглобина.csv
В нём содержатся среднее значение гемоглобина и стандартное отклонение по возрастным группам.
